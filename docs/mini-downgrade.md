# Mini: только откат/обновление прошивки (без ADB)

Режим **OTA-only** — стенд отдаёт колонке манифест обновления и сам файл прошивки,
а всё остальное (регистрация, `get_sync_info`, авторизация, метрика) прозрачно
уходит в настоящий Яндекс.

ADB в этом режиме **не включается** — проверено на Station Mini 1 (`1.369.x`):
прошивка игнорирует поле `adbd` в ответе `/get_sync_info`, а без root маркеры
`/data/quasar/activate_adb_*` не создать. Поэтому для Mini имеет смысл только
доставка прошивки (откат на нужную сборку), а не активация ADB.

## Когда использовать

- нужно откатить/обновить Mini на конкретную сборку (`1.369.4.46…`);
- ADB не нужен (или нужен, но другим способом — этот режим его не даёт).

Для Lite режим не нужен: там работает обычный режим с активацией ADB.

## Подготовка прошивки

```bash
cd ~/lite-kit/firmware
rm -f *.zip manifest.json
BASE="http://<ваш-сервер>/yandexmini/1.369.4.46.4778368993.20261013"
curl -fL -o "1.369.4.46.4778368993.20261013.zip" "$BASE/update.zip"
ls -l
```

Имя файла важно: из него берутся версия и платформа (`1.x` → `yandexstation`).

## Запуск

```bash
cd ~/lite-kit
touch run/ota_only          # включить режим «только прошивка»
./stop.sh && sudo ./start.sh
```

В баннере появится:

```
режим          : только прошивка (OTA-only)
```

Выключить режим: `rm run/ota_only` и перезапустить стенд.

Альтернатива без файла-флага:

```bash
sudo env EQUASAR_MODE=ota ./start.sh
```

## Что происходит

```
DNS: quasar.yandex.net / .ru / scbh.yandex.net -> IP мака
GET  /check_updates   → наш манифест (hasUpdate: true, fallbackIp = IP мака)
GET  /yandexstation/ota/<файл>.zip → отдаём файл с диска (Range поддерживается)
всё остальное         → proxy в настоящий Яндекс
```

## Проверка

```bash
curl -k -s -H "Host: quasar.yandex.net" -H "User-Agent: yandexmini/1.369.4.46" \
  "https://127.0.0.1/check_updates?device_id=test&version=0.1"
```
Должно вернуть вашу версию и `fallbackIp`.

## Ограничения

- Подпись прошивки проверяется станцией — изменённый образ она не примет,
  режим годится только для **официальных** образов.
- ADB не включается. Для Mini с прошивкой `1.369` публичного пути через
  `/get_sync_info` нет.

## Проверка режима OTA-only

```bash
./scripts/test-ota.sh            # через 127.0.0.1
./scripts/test-ota.sh 192.168.0.109
```

Скрипт проверяет: манифест совпадает с файлом (версия, crc32, downloadUrl),
полную отдачу zip, поддержку `Range` (206) и то, что `/get_sync_info` уходит
в Яндекс (то есть ADB в этом режиме не включается).
